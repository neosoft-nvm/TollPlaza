# Credits

Toll Plaza is its own code, but it learned a lot from other Cities: Skylines II modders who shared their work. Thank you:

- **willmakesrandomshit**, [Road Rules — Lane & Vehicle Restrictions](https://github.com/willmakesrandomshit/RoadRules): its source showed how to close a lane reliably. You hand the lane's data straight to the game's route finding and send it again every so often. Closed booths are built on that idea.
- **Javapower77**, [Tollbooth Highways](https://github.com/Javapower77/cs2-tollbooth-highways): the first functional tollbooth mod for CS2. Its code and notes showed how vehicles can be stopped and charged at a booth, and where toll systems fit in the game's update order.
- **krzychu124** ([Traffic](https://github.com/krzychu124/Traffic)): notes on the game's system update order, shared on the CS2 modding Discord and kept in Tollbooth Highways' docs.
- **Triton Supreme (AlphaGaming7780)**, [Extra Assets Importer](https://github.com/AlphaGaming7780/ExtraAssetsImporter) / ExtraLib: a reference for how custom assets and textures are imported into the game.
- The **CS2 modding Discord** community, whose shared answers show up in all of the above.

No code was copied from these projects. Only the ideas were used.
